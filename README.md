# דף נחיתה — מיסטר

הריפו הזה מחובר ל‑Vercel. **כל דחיפה ל‑`main` מעלה את האתר לאוויר אוטומטית**, תוך כדקה.
אין צורך להתעסק בהגדרות אחסון, שרת, SSL או דומיין — הכל כבר מוגדר.

## איך מתחילים

```bash
git clone <כתובת-הריפו>
cd mister-landing
```

כרגע יש כאן `index.html` זמני (דף "בקרוב"). אפשר פשוט למחוק אותו ולהעלות את הדף במקומו.

## מה אפשר להעלות לכאן

**אתר סטטי (HTML/CSS/JS)** — הכי פשוט. שימו `index.html` בשורש הריפו, לצד כל קובץ CSS/JS/תמונה. Vercel מגיש את זה כמו שהוא, בלי שום הגדרה.

**פרויקט עם בילד (Next.js / Vite / Astro / וכו')** — גם עובד. Vercel מזהה את הפריימוורק לבד מתוך `package.json` ומריץ את הבילד. רק ודאו שהפרויקט בשורש הריפו ושהוא נבנה נקי אצלכם לפני הדחיפה.

> אם אתם מחליפים מאתר סטטי לפרויקט עם בילד (או להפך), תעדכנו אותי — ייתכן שצריך לאמת את הגדרות הבילד בפאנל של Vercel פעם אחת.

## תצוגה מקדימה לפני עלייה לאוויר

אל תדחפו ישר ל‑`main` אם אתם לא בטוחים. פתחו ענף:

```bash
git checkout -b my-changes
git push origin my-changes
```

Vercel בונה אוטומטית **Preview** לכל ענף ולכל Pull Request, ונותן כתובת נפרדת לבדיקה.
רק מיזוג ל‑`main` מעלה לאוויר.

## כללים קצרים

- הדף בעברית — שמרו על `dir="rtl"` ו‑`lang="he"` בתגית `<html>`.
- תמונות וקבצים כבדים — לדחוס לפני העלאה. אין צורך ב‑CDN חיצוני, Vercel מגיש הכל דרך CDN.
- סודות (מפתחות API, טוקנים) — **לא** בתוך הקוד. תגידו לי ואני אגדיר אותם כמשתני סביבה ב‑Vercel.
- פיקסלים ותגי מעקב (Meta / Google) — אפשר להדביק ישר ב‑`<head>`.
- לא לדחוף `node_modules` או קבצי בילד — הם כבר ב‑`.gitignore`.
- הפאביקון (`favicon.ico` בשורש + `assets/favicon-*.png`, `assets/apple-touch-icon.png`) ותגיות ה‑`<link rel="icon">` שב‑`<head>` — להשאיר. זה הסמל של מיסטר בלשונית הדפדפן.

## שאלות

כל מה שקשור לדומיין, לאחסון, ל‑SSL או להגדרות Vercel — דרכי.
